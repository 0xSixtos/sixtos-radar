# Contribuir

Puedes modificar tu fork bajo la licencia MIT. No hace falta pedir acceso al repositorio original.

Para proponer una mejora común:

1. Crea una rama en tu fork.
2. Cambia las fuentes en `config.json` o modifica el código.
3. Ejecuta `python3 -m unittest -v` y, si cambias fuentes, `python3 radar.py --dry-run`.
4. Envía un pull request explicando qué cambia y cómo lo comprobaste.

Usa fuentes primarias con RSS/Atom público y HTTPS. No subas credenciales, datos privados ni feeds con tokens. Mantén el monitor sin dependencias o servicios de pago por defecto.

Las preferencias personales de horario o temas pueden quedarse en tu copia; no hace falta cambiarlas en la configuración de todas las personas. Si propones mejoras al envío, incluye pruebas con Discord simulado: CI no necesita tu webhook.

Los mantenedores revisarán el código antes de integrarlo. La licencia del proyecto cubre el código; no otorga derechos sobre artículos, marcas o contenidos externos.
